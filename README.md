# MediaLooped Studio

**Turn family memories into cinematic documentaries using AI.**

MediaLooped Studio is a privacy-first desktop application for busy families who want to transform vacation photos and videos into timeless, Netflix-style travel documentaries with minimal manual work.

## Current status

- v0.1 — Folder scanner
- v0.2 — Metadata report, technical scoring, and duplicate detection
- v0.3 — Vacation timeline *(next)*

## Current capabilities

- Scan a vacation folder
- Count photos and videos
- Calculate total media size
- Read available Mac metadata
- Detect likely exact duplicates
- Create CSV, TXT, and HTML reports
- Run locally without uploading family media

## Product goal

A parent should be able to select a vacation folder, click one button, and receive a polished documentary draft with almost no editing work.

## Privacy

MediaLooped is designed to run locally whenever possible. Family photos and videos should never be uploaded without clear permission.

## Development

The current prototype is written in Python and tested on macOS.
