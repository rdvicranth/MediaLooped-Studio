# MediaLooped Roadmap

## Phase A — Organize

### v0.1
- Scan a selected folder
- Count photos and videos
- Calculate total size
- Export inventory

### v0.2
- Read technical metadata
- Detect likely exact duplicates
- Create preliminary quality scores
- Export HTML report

### v0.3
- Group media by capture date
- Build a day-by-day vacation timeline
- Export a visual HTML timeline

## Phase B — Understand

### v0.4
- Detect broad scenes such as lakes, mountains, roads, wildlife, and buildings
- Identify portrait, group, and scenic media
- Add searchable tags

### v0.5
- Score emotional and storytelling value
- Suggest hero shots
- Suggest opening, transition, and ending clips

## Phase C — Tell the story

### v0.6
- Build a documentary storyboard
- Suggest a beginning, middle, and ending
- Generate narration prompts

### v0.7
- Create a first edit decision list
- Recommend clip lengths and pacing
- Suggest music mood

## Phase D — Create

### v1.0
- Generate a first movie draft
- Export for final review
- Create family-film and faceless-documentary modes
